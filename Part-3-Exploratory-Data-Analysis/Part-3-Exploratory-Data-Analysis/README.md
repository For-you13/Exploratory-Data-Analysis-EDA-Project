# Part 3 — Exploratory Data Analysis (EDA)

This project analyzes a retail sales dataset to uncover patterns, trends, correlations, and business insights.

## Features
- Statistical summaries
- Missing-value analysis
- Duplicate checking
- IQR-based outlier analysis
- Category, region, segment, and city analysis
- Monthly sales and profit trends
- Correlation analysis
- 14 visualizations
- Structured EDA report

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Run
```bash
pip install -r requirements.txt
python eda_analysis.py
```

## Structure
- `data/` — raw dataset
- `reports/` — CSV summaries and EDA report
- `visualizations/` — charts
- `eda_analysis.py` — complete analysis script
- `requirements.txt` — dependencies
